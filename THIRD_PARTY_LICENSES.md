# Third-party software

All dependencies are installed from PyPI at install time. None are bundled in this repository.
No copyleft (GPL / AGPL / LGPL) licence is used. Licences below were read from the installed package metadata.

| Package | Tested version | Licence | Used for |
|---|---|---|---|
| Flask | 3.1.3 | BSD-3-Clause | web server |
| Werkzeug | 3.1.9 | BSD-3-Clause | Flask internals, `secure_filename` |
| Jinja2 | 3.1.6 | BSD-3-Clause | HTML templates (auto-escaping on) |
| pandas | 3.0.2 | BSD-3-Clause | CSV handling, feature engineering |
| NumPy | 2.4.4 | BSD-3-Clause (plus 0BSD, MIT, Zlib, CC0 parts) | numerics |
| scikit-learn | 1.8.0 | BSD-3-Clause | scaler fitting, metrics, train/test split |
| TensorFlow / Keras | 2.21.0 / 3.15.1 | Apache-2.0 | the neural network |
| Matplotlib | 3.10.8 | Matplotlib licence (PSF-based, permissive) | charts; bundles DejaVu fonts (permissive Bitstream Vera/DejaVu licence) |
| NetworkX | 3.6.1 | BSD-3-Clause | circular-trading ring detection |

## Obligations
- Keep each package's licence text with any redistributed copy (pip installs it in `*.dist-info/`).
- Apache-2.0 (TensorFlow, Keras): keep the NOTICE file if you redistribute the packages themselves.
- BSD / PSF: keep the copyright notice and do not use the authors' names to endorse your product.

## Data and services
- The dataset is generated by `generate_dataset.py` (random, synthetic). No real taxpayer data, no third-party datasets.
- GSTINs in the data are fictional placeholders.
- The app makes no outbound network calls and loads no CDN scripts, fonts or analytics (the Content-Security-Policy blocks them).

## Re-check licences and CVEs any time
    pip install pip-licenses pip-audit
    pip-licenses --format=markdown
    pip-audit -r requirements-lock.txt
